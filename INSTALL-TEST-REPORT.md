# Проверки 6.3

41 автоматический тест: прежние серверные/PDF-регрессии, выбор стартового СТО, отдельные манифесты, отсутствие утечки другого СТО и загрузка публичной оболочки без настроенного подключения базы.

Chromium: 11 сценариев — первоначальная загрузка, ошибка, ожидание внутри приложения, главная 320/390px, услуги 320px, вход 320px, запись 320px, инструкция Safari, запрос установки и установленный режим. Нет исключений JS или горизонтального переполнения страницы. Обработчик beforeinstallprompt вызывается один раз; appinstalled/standalone скрывают кнопку. Нативные install-события моделировались: это не доказательство физической установки на Android/iPhone.

Визуально просмотрены стартовая/ошибочная страницы, мобильные экраны, инструкция и исправленные цены/форма. Найденные отдельный перенос «мин» и тесные подписи чекбоксов устранены. Примеры используют только синтетические данные, не вашу боевую базу.

Production-деплой и реальная установка на телефоне пока не проверены. SQL-схема не изменялась.
