# ПИТ — редизайн Nightshift

## Что обновлено

Единый графитово-фиолетовый интерфейс по предоставленным референсам:
- клиентское приложение: вход, регистрация, главный экран, гараж, формы автомобиля, запись в три шага, визиты, находки и чат, профиль, уведомления, сервис, история;
- рабочее место мастера: посты, очередь, работы, находки и склад шин;
- админка: обзор, записи, настройки, команда, склад, сервисы и журнал;
- запуск приложения, ошибка подключения, окно установки, PWA-иконки и системный цвет.

Крупные карточки, автомобильные изображения из исходного проекта, контрастная типографика, единые кнопки и поля. Убраны наклоны карточек; поддерживается reduced-motion. Все изображения и шрифты локальные. Новых runtime-зависимостей нет.

Бизнес-логика, API, схема БД и генерация PDF не переработаны. В сервере изменены только визуальные значения по умолчанию: акцент и цвет PWA. В существующей базе данные не мигрируются.

## Обновление существующего проекта

1. Сделайте резервную копию/commit текущего проекта.
2. Перенесите исходники из этого архива в репозиторий (изменённые файлы перечислены в REDESIGN-FILES.txt).
3. Не заменяйте свои секреты и переменные окружения. .env.example остаётся шаблоном.
4. Выполните `npm ci`, `npm test`, `npm run build` и обычный redeploy.
5. Если сервис уже существует, его фирменный цвет сохранится. Для фиолетового вида из превью откройте «Настройки СТО» и задайте цвет `#8050EE`, затем сохраните.
6. PWA-кэш имеет новую версию. Если установленное приложение показывает старый дизайн, закройте и откройте его; при необходимости обновите страницу.

Миграции БД для редизайна не нужны. Для запуска production по-прежнему требуется исходная конфигурация PostgreSQL/Supabase из README.md.
