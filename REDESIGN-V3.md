# ПИТ — дизайн V3 / Monochrome Performance

## Визуальное направление
Единая чёрно-графитовая система с красным акцентом #EC0618. Фиолетовая подложка каталога и отдельная каталожная палитра убраны. Унифицированы поверхности, рамки, скругления, заголовки, стрелки, выбор услуг, карточки автомобиля, рабочие панели и настройки. Фотографии услуг сохранены; это иллюстрации категорий, а не фотографии конкретной компании.

## Изменения относительно V2
- pit/design.css: единая палитра и доработка компонентов/адаптивности.
- pit/shared.js: согласованные заголовок и подпись каталога.
- pit/sw.js: новая версия кэша для обновления ресурсов.
- Документация V3 и свежие снимки интерфейса в redesign-preview.

Бизнес-логика, авторизация, изоляция компаний, API и схема базы данных в этом обновлении не изменялись. Здесь нет новой системы подписок или автоматического white-label-провижининга.

## Проверки
- 41/41 автоматических тестов проходят.
- Сборка статических ресурсов и проверка синтаксиса JavaScript проходят.
- Проверены ширины 320, 390, 460 и 1440 px: главная, услуги, гараж, запись; горизонтального переполнения страницы нет.
- Переход из реального каталога к записи сохраняет выбранную диагностику.
- Визуально проверены 7 ключевых экранов: клиентские экраны, заказ мастера, обзор и настройки владельца.

## Запуск и обновление
Используйте инструкции README.md и DEPLOY-START-HERE.md. Выполните npm ci, npm run build и запуск с переменными вашего окружения. Зависимости и сгенерированная папка public в архив не включены.

Фирменный цвет уже существующей компании автоматически не перезаписывается. Если ранее сохранён фиолетовый акцент, для оформления как в демонстрации задайте в настройках компании #EC0618. Это пользовательская настройка, а не отдельная палитра каталога.

## Рекламные материалы
Новый отдельный комплект PIT-sales-kit-v3.zip содержит вертикальную и горизонтальную рекламу, по 18 секунд со звуком, и обновлённый конструктор персонального визуального демо. Это рекламный монтаж реальных экранов V3 с движением, крупной типографикой и синтезированным ритмическим саунд-дизайном; не запись последовательного заполнения форм. Все клиентские данные демонстрационные.

Production-развёртывание, push в GitHub, отправка компаниям, проверка на физическом iPhone/Safari и production PostgreSQL в эту работу не входят. Этот документ заменяет REDESIGN-V2.md; старые отчёты в проекте относятся к предыдущим этапам.
