# ПИТ — редизайн V2

Это полный рабочий проект с утверждённым направлением V2, не HTML-концепция.

## Визуальная система

- Чёрные поверхности, яркий красный акцент, крупная узкая типографика, автомобиль и индекс модели в центре композиции.
- Фиолетовый каталог услуг с изображениями деталей вместо декоративных линейных пиктограмм. Каталог открывается по вкладке «Сервис»; контакты СТО и маршруты сохранены ниже услуг.
- В форме записи показаны фактический автомобиль и выбранные категории работ. Цены, длительности, доступность и подтверждение по-прежнему приходят с сервера.
- Единый стиль клиента, рабочего места мастера, админки, входа/регистрации, гаража, визитов, находок/чата, склада, профиля, истории, запуска, ошибок подключения и окна установки.
- Для длинных и вручную введённых моделей предусмотрен компактный заголовок; при отсутствии изображения остаётся текстовый автомобиль. Для нестандартных услуг — нейтральная пиктограмма без неподходящей фотографии.
- Фотографии категорий услуг — сгенерированные иллюстрации в `pit/img/services/`, не фотографии конкретных деталей клиента. Автомобили и шрифты сохранены из исходного проекта. Все ресурсы локальные, новых runtime-зависимостей нет.

## Установка поверх существующего проекта

1. Сделайте резервную копию или commit текущего проекта.
2. Перенесите исходники из архива в репозиторий. Список новых и изменённых относительно исходного PIT-main.zip файлов: REDESIGN-FILES.txt.
3. Сохраните свои секреты и настройки подключения. `.env.example` — только шаблон, не готовая конфигурация production.
4. На Node.js 24 выполните `npm ci`, `npm test`, `npm run build`, затем обычный redeploy. Локальный production-запуск: `npm start` при заданных переменных окружения из README.md.
5. У существующего СТО уже сохранённый фирменный цвет не меняется автоматически. Для точного вида V2 установите в «Настройки СТО» → «Фирменный цвет» значение `#EC0618` и сохраните. Фиолетовый каталог услуг независим от этого цвета.
6. PWA-кэш обновлён до новой версии. При старом виде после обновления закройте приложение и откройте вновь/обновите страницу.

Схема БД, API, авторизация, расчёт доступности и цены, подтверждение записи, согласования и PDF-генератор не переработаны. Миграции базы для редизайна не нужны. В сервере изменены только визуальные значения по умолчанию: акцент и цвет PWA. При переносе сохраняйте свою production-конфигурацию.

## Проверки

- `npm test`: 41 тест из 41 успешно.
- `npm run build`: успешно; синтаксис клиентских и серверных JS-файлов проверен.
- Локальный сценарий Chromium/SQLite: 41 экран/состояние без JavaScript-ошибок, отсутствующих изображений и горизонтального переполнения страницы.
- Визуально проверен 21 основной экран/состояние: главная, каталог, три шага записи, вход, гараж, посты и работа мастера, склад, находки/чат, мобильная админка, её настройки, запуск, установка и шесть desktop-разделов админки.
- Дополнительно проверены ширины 320, 390, 460 и 1440 px, длинная ручная модель без фото, нестандартная услуга, открытие настоящей формы из карточки услуги и получение реальных слотов с локального сервера.
- Белый текст на красном акценте сохранён при достаточном контрасте; для светлых фирменных цветов автоматически используется чёрный. Поддерживается reduced-motion.

Превью в `redesign-preview/` — скриншоты настоящих рабочих экранов на искусственных тестовых данных. База и аккаунты локального стенда не включены. Исходные автоматические тесты сохранены и содержат собственные искусственные тестовые данные. Локальных журналов в архиве нет.

Production-деплой, реальное подключение к PostgreSQL/Supabase и проверка Safari/iOS не выполнялись. GitHub не обновлялся. Старые отчёты в корне относятся к исходному проекту; результаты именно редизайна приведены здесь.
