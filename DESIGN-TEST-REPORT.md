# Проверки дизайна 6.2

- 37 предыдущих автоматических серверных/PDF-тестов: без ошибок.
- Chromium: 9 состояний интерфейса — главный экран, плитки услуг, запись, визит/PDF, обзор владельца, тёмный обзор, мобильная админка, настройки и вход. Исключений JavaScript и горизонтального переполнения страницы нет.
- Реальный CSS matrix3d на плитке при движении мыши проверен в браузере. При prefers-reduced-motion трансформация отключается. На сенсорном viewport курсорный наклон не включается.
- Скачивание PDF после смены оформления проверено в браузере.
- Снимки экранов 390px и 1440px отрендерены и просмотрены по отдельности; перекрытий интерфейса навигацией не обнаружено. Светлая и тёмная темы проверены.

Браузерные примеры используют синтетические данные и тестовые ответы API. Они не являются снимками вашей боевой базы. Серверные тесты используют изолированный тестовый адаптер. Production-деплой новой версии ещё не проверен.
