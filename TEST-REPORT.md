# Проверки выпуска v5

В локальном тестовом окружении: Node.js 24.14.1, SQLite, Chromium.

## API: 20 из 20 пройдено

Проверены: реальная авторизация, отсутствие доступа к настройкам у клиентов и мастеров, версия настроек, регистрация, каталог, сохранение автомобиля, расчёт цены на сервере, блокировка пересекающихся записей, доступ только к собственным заказам, создание мастера, приёмка, фото находки, решение только клиентом, запрет повторного согласования, цена/длительность дополнительных работ, двусторонний чат, запрет преждевременного закрытия, завершение работ, уведомления, склад и повторная занятость, публичная история без телефона/номера, настоящий QR, отзыв ссылок, независимые СТО, экспорт без хешей паролей, журнал, отзыв сессии после смены пароля, защита Origin и валидация.

## Браузерные сценарии

Вход владельца, редактирование/сохранение настроек, разделы сотрудников и сервисов, мобильная регистрация, поиск Golf II, добавление машины 1990 года, сохранение пробега и номера, выбор услуги, доступные окна, подтверждение записи, сообщение в чат, история и контакты. Проверено отсутствие горизонтального переполнения на 1440px и 390px в этих сценариях. Исправлена валидация HTML pattern для новых браузеров.

QR-модуль отдельно декодирован OpenCV: URL совпал с исходным.

Это не подтверждение подключения ваших камер, SMS, Telegram, OCR или платёжной системы: эти интеграции не установлены. Не является полным аудитом безопасности, нагрузочным тестом или проверкой Docker на вашем сервере.
