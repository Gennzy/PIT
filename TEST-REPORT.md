## Границы проверки

Локальные API-тесты используют отдельный SQLite тестовый драйвер для проверки асинхронной логики; в production SQLite запрещён. Драйвер PostgreSQL реализован через pg и должен быть установлен обычным npm install на Vercel. Node → Supabase через реальные секреты/SSL пока не проверялся: секреты вводит владелец в Vercel, не в чат.

Storage upload/read проверен с подменой HTTP-ответов, не реальной загрузкой файла с серверным ключом. Реальный приватный bucket создан и проверен. Проверка rewrite выполнена в локальном моделировании обработчика, не на опубликованном Vercel. Сам live deploy и его текущий статус не подтверждены.

Это не аудит безопасности, нагрузочное испытание или подтверждение безлимитной бесплатной эксплуатации. Никакие платные тарифы/add-ons не включались.
