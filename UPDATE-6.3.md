# ПИТ 6.3 — загрузка, установка и мобильные шрифты

Архив включает предыдущие улучшения дизайна и заказ-наряд PDF. Можно установить поверх подготовленной версии 6.0, 6.1 или 6.2 одним обновлением.

## Что изменено

Оформленная стартовая страница с брендом, объёмным символом, описанием приложения и индикатором подключения вместо пустого сообщения. Корневая страница на Vercel отдаётся статически; оболочка приложения/админки не ждёт подключения базы. Данные и действия по-прежнему доступны только через защищённый сервер. При проблеме подключения показывается понятное состояние с кнопкой повтора, а не выдуманные записи.

Заметная кнопка «Добавить на экран» расположена сверху — до входа в аккаунт и внутри приложения. Когда Chrome/Edge предоставляет системный запрос установки, кнопка открывает его. Если запрос недоступен, открывается инструкция. На iPhone/iPad используется Safari → Поделиться → На экран «Домой» → Добавить: автоматической установки через JavaScript iOS не предоставляет. Во встроенных браузерах мессенджеров может потребоваться открыть ссылку в обычном браузере. При запуске уже установленного приложения баннер скрывается.

Манифест каждого СТО запускает именно его страницу. Прежний идентификатор основного приложения сохранён для совместимости. Установка не является push-подпиской и не добавляет SMS/Telegram.

На телефонах используются системные шрифты и адаптивные заголовки. Поля имеют размер 16px, суммы/единицы времени не разрываются, госномер держится одной строкой. На узких телефонах форма выбора услуг — удобные широкие строки. Длинные названия могут занимать две естественные строки: весь текст не сжимается до нечитаемого размера и не обрезается.

## Установка обновления

1. Сохраните текущий Git-коммит.
2. Скопируйте ВСЕ файлы PATCH-архива в корень Gennzy/PIT с заменой, без дополнительной вложенной папки. Обязательно обновите vercel.json и новые файлы запуска/установки/стилей, а также server/fonts для PDF.
3. Commit + Push — подключённый Vercel выполнит сборку и публикацию.
4. Обновите страницу; установленную PWA закройте и откройте снова. Если видна старая версия, обновите приложение повторно после загрузки нового service worker.

DATABASE_URL и остальные секреты/переменные окружения менять не нужно. SQL не запускать: новых миграций нет, существующие клиенты и записи остаются в прежней базе. Никаких платных сервисов и новых зависимостей не добавлено.

Помощник подготовил файлы, но не отправлял их в GitHub и не публиковал на Vercel. После деплоя проверьте загрузку на своей ссылке, вход, запись и PDF. Настоящую установку необходимо подтвердить на своём телефоне; браузер решает, когда доступен системный запрос.
