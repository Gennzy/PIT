# ПИТ 6.2 — объёмные плитки и анимация

Обновление поверх ранее подготовленной версии Vercel + Supabase (6.0 или 6.1). Архив включает также заказ-наряд PDF из этапа 1, поэтому отдельно устанавливать предыдущий PDF-патч не требуется.

## Что изменилось

- Новые поверхности, мягкие тени, градиенты и глубина карточек.
- Плитки услуг, автомобиля, визитов и показателей получают небольшой настоящий CSS 3D-наклон при движении мыши на компьютере.
- Плавное однократное появление карточек при входе в видимую область.
- Иконки услуг, уведомлений и навигации, обновлённые кнопки и состояния фокуса.
- Светлая/тёмная админка следует настройке устройства. Клиентское приложение сохраняет тёмную тему.
- Фирменный цвет каждого СТО берётся из его существующих настроек. Цвет текста основных кнопок подбирается под светлый/тёмный акцент.
- Нижняя навигация занимает своё место в макете и не перекрывает содержимое. Содержимое приложения прокручивается внутри экрана.

Это CSS 3D-интерфейс, а не 3D-модели автомобилей или WebGL-сцена. Никаких новых платных сервисов, библиотек или запросов на сторонние серверы не добавлено.

## Движение и производительность

На сенсорном телефоне курсорный наклон отключён. Поля и формы не наклоняются, чтобы не мешать вводу. При системной настройке «уменьшить движение» анимация и наклоны отключены. Нет бесконечного вращения или постоянно работающего анимационного цикла; при скрытии вкладки эффекты приостанавливаются.

## Как установить

1. Сохраните текущий Git-коммит как точку возврата.
2. Распакуйте PATCH-архив и скопируйте его файлы в корень Gennzy/PIT с заменой. Не создавайте дополнительную вложенную папку. Загрузите новые design.css и motion.js вместе с обновлёнными HTML-файлами, а также server/fonts для PDF.
3. Commit + Push — подключённый Vercel соберёт обновление.
4. После успешной публикации обновите страницу. Для установленной PWA закройте и снова откройте приложение; обновление кеша может потребовать повторной загрузки.

DATABASE_URL и остальные переменные окружения НЕ менять. SQL повторно НЕ запускать: схемы Supabase не изменялись. Клиенты, записи, автомобили и настройки сохраняются в прежней базе.

Этот архив содержит код обновления, а не готовый опубликованный деплой. Помощник не отправлял изменения в GitHub и не публиковал их на Vercel. После публикации проверьте вход, запись, карточку заказа и скачивание PDF со своей учётной записью.
